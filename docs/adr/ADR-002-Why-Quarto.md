# ADR-002 — Why Quarto

**Status:** Accepted

**Date:** 2026-08-01

## Context

DiveLab requires a book, website, PDF and executable notebooks.

## Decision

Adopt Quarto as the single publishing source.

## Consequences

### Positive
- One source generates multiple outputs.

### Trade-offs
- Initial learning curve.

## Educational Impact

Students and contributors work from a single canonical source.
