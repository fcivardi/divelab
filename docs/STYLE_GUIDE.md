# DiveLab Style Guide

## Writing Philosophy
- Explain physics before mathematics.
- Build intuition before formalism.
- Use British English.
- Prefer active voice.

## Standard Chapter Flow
Observation → Question → Model → Mathematics → Simulation → Interpretation.

## Mathematics
- Use `$...$` for inline equations.
- Define every symbol before first use.
- Always include units.

## Figures
- Caption every figure.
- Label axes with units.

## Callouts
- Engineering Question
- DiveLab Insight
- Common Misconception
- Simulation
